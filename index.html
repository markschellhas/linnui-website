Go GUI Framework — Declarative UI for Go

v0.3.1

LinnUI is a modern Go GUI framework for building beautiful, reactive, cross-platform applications — inspired by Flutter, SwiftUI, and Jetpack Compose, powered by Gio.

The Go GUI library developers actually want

Go developers deserve a GUI for Go that feels modern — not a webview wrapper or a low-level drawing API. LinnUI is a declarative Go UI framework with composable widgets, reactive state, and Material 3 themes. Write your entire interface in pure Go and ship tiny static binaries with GPU-accelerated rendering. No cgo. No embedded browser.

Why choose LinnUI for your Go GUI?

  • Flutter-like declarative API Composable widgets — Scaffold, Column, Row, Container — with concise, readable syntax for any Go desktop GUI.
  • Reactive state management Svelte-inspired stores that automatically redraw the UI when your Go GUI state changes.
  • Material 3 themes Beautiful light and dark defaults with smooth animations out of the box.
  • Pure Go, native performance A true native Go GUI — no webviews, no cgo. GPU-accelerated via Gio for fast, lightweight apps.
  • True cross-platform One codebase for desktop (Windows, macOS, Linux), mobile (Gomobile), and WebAssembly.

Install LinnUI v0.3.1

Requires Go 1.26+. Linux desktop builds also need Gio system libraries.

go get github.com/markschellhas/linnui/ui@v0.3.1

Quick example

package main

import (
    "gioui.org/app"
    ui "github.com/markschellhas/linnui/ui"
)

func main() {
    count := ui.NewState(0)
    go func() {
        w := new(app.Window)
        w.Option(app.Title("LinnUI Counter"))
        count.Bind(w)
        // ... event loop with declarative widgets
        app.Main()
    }()
}

See the full reactive counter demo in the examples/counter directory.

Frequently asked questions

What is LinnUI?
LinnUI is a declarative Go GUI framework built on Gio with Flutter-like widgets, reactive state, and Material 3 themes for desktop, mobile, and WASM.
How is LinnUI different from webview-based Go GUI tools?
LinnUI renders natively through Gio with GPU acceleration. You get real Go GUI performance and tiny binaries — not an embedded Chromium shell.
What platforms are supported?
Windows, macOS, Linux, mobile via Gomobile, and WebAssembly — all from a single Go codebase.
Is LinnUI production-ready?
LinnUI v0.3.1 is in active development. The API may change — see the changelog for release history. Contributions welcome.
